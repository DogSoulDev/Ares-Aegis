## 📋 Descripción

**Ares Aegis** es una suite integral de ciberseguridad diseñada para profesionales de seguridad, estudiantes y entusiastas. Proporciona herramientas avanzadas de detección, análisis y protección con una interfaz moderna y fácil de usar.

## 🚀 Características Principales

- **🔍 Escaneador de Malware**: Detección multicapa con análisis heurístico
- **📡 Monitor de Red**: Supervisión en tiempo real de conexiones y tráfico
- **⚡ Monitor de Procesos**: Vigilancia continua de procesos del sistema
- **🔐 Auditoría PAM**: Verificación de configuraciones de autenticación
- **🏥 Sistema de Cuarentena**: Aislamiento seguro de archivos maliciosos
- **📊 Reportes HTML**: Generación de informes detallados
- **🔧 Constructor de Wordlists**: 15+ wordlists especializadas incluidas
- **📚 CheatSheets**: Biblioteca de herramientas de pentesting
- **🎨 Temas Personalizables**: Interfaz adaptable con 5 temas de Kali Linux

## 📦 Instalación

### Requisitos
- **Sistema Operativo**: Kali Linux (optimizado) o Windows 10/11
- **Python**: 3.8 o superior
- **RAM**: Mínimo 2GB, recomendado 4GB
- **Espacio**: 1GB libre para logs y cuarentena

### Instalación Rápida

```bash
# Clona el repositorio
git clone https://github.com/DogSoulDev/Ares-Aegis.git
cd Ares-Aegis

# Ejecuta el programa
sudo python main.py
```

> **💡 Nota:** No requiere instalación de dependencias externas. Utiliza únicamente la biblioteca estándar de Python.

## 🎮 Uso Básico

1. **Primer Inicio**: Ejecuta `sudo python main.py`
2. **Escaneo Rápido**: Ve a "🔍 Escaneador" y selecciona un directorio
3. **Monitorización**: Activa los monitores de red y procesos
4. **Personalización**: Cambia temas en "⚙️ Configuración"
