# Ares Aegis - Sistema de Seguridad Avanzado
# Requisitos del Sistema - Solo módulos estándar de Python

# === NOTAS IMPORTANTES ===
# Este proyecto usa ÚNICAMENTE módulos estándar de Python 3.8+
# No requiere instalación de paquetes externos

# === MÓDULOS ESTÁNDAR UTILIZADOS ===
# - tkinter: Interfaz gráfica de usuario
# - subprocess: Ejecución de comandos del sistema
# - pathlib: Manipulación de rutas
# - hashlib: Cálculo de checksums
# - json: Serialización de datos
# - sqlite3: Base de datos local
# - datetime: Manejo de fechas y tiempo
# - os: Operaciones del sistema
# - re: Expresiones regulares
# - threading: Multihilo
# - logging: Sistema de logs
# - unittest: Framework de testing

# === HERRAMIENTAS DEL SISTEMA REQUERIDAS ===
# Para funcionalidad completa, se requieren estas herramientas del sistema:
# - ps: Monitoreo de procesos
# - netstat: Análisis de red
# - ss: Análisis de sockets (alternativa a netstat)
# - kill: Terminación de procesos
# - find: Búsqueda de archivos
# - md5sum, sha256sum: Cálculo de checksums
# - clamav (opcional): Análisis antivirus externo

# === INSTALACIÓN DE HERRAMIENTAS DEL SISTEMA ===
# En Debian/Ubuntu/Kali Linux:
# sudo apt update
# sudo apt install clamav clamav-daemon net-tools procps coreutils

# === COMPATIBILIDAD ===
# - Python 3.8 o superior
# - Sistemas Linux (Debian, Ubuntu, Kali Linux)
# - Privilegios de root requeridos para funcionalidad completa

# === FILOSOFÍA DEL PROYECTO ===
# Este proyecto demuestra que es posible crear software de seguridad
# robusto usando únicamente las herramientas estándar de Python,
# sin dependencias externas que puedan introducir vulnerabilidades
# o problemas de compatibilidad.
